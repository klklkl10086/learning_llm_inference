调度问题的最小复现（项目根目录、现有 Python 环境）：

```python
from llm_inference.scheduler import Scheduler

scheduler = Scheduler(max_active_requests=2, max_batch_input_tokens=16)
scheduler.add_request("r1", [1, 2, 3], max_new_tokens=2)
plan = scheduler.schedule()
scheduler.update(plan.batch_id, {"r1": 4})
```

当前执行到最后一行会报 NameError；此时 r1 的逻辑计算进度已为 3。两个调度版本均复现。这个例子只检查调度状态，没有执行模型。
